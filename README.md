# Product Inventory Manager

An interactive, browser-based inventory management dashboard built using TypeScript and modern web standards. The application demonstrates core TypeScript principles—including strict type safety, custom interface hierarchies, functional array transformations, and event-driven DOM manipulation—without external UI libraries.

## Key Features
- **Type-Safe Data Architecture:** Utilizes extended TypeScript interfaces (`Product` and `DiscountedProduct`) for structured data modeling.
- **Dynamic State Management:** Supports real-time addition of inventory items, automatic ID generation, and toggling stock availability.
- **Data Filtering & Operations:** Includes functional transformations (`map`, `filter`) for viewing in-stock items and applying dynamic discount calculations.
- **Clean UI Component Rendering:** Modular DOM rendering engine written in pure TypeScript with zero runtime overhead.
- **Continuous Deployment:** Compiled via `tsc` to modern JavaScript (ES6) and deployed via GitHub Pages.
